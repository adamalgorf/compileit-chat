# Evaluation report

Generated by `make eval` (`backend/tests/eval/`). It runs the golden questions in
[`golden.yaml`](../backend/tests/eval/golden.yaml) through the real stack, the same path as
the API: `AskQuestion` → LangGraph orchestrator → OpenAI. Each case gets a fresh session.
Real model calls, so this is not part of CI.

## Method

- **Cases** (18):
  - the five case questions;
  - two follow-up pairs (only the second turn is scored, so it must be understood in context);
  - six more answerable questions probing exact terms, names and specific pages;
  - two on-topic questions the site does not answer;
  - four out-of-scope questions, including a prompt-injection attempt.
- **Retrieval hit rate** comes in two forms:
  - the hybrid retriever's top 5 chunks for the raw question;
  - whether the agent's own tool calls returned an expected page.
- **Citations**: whether the answer links a source, and whether it is an expected page.
- **Refusal / "not found" correctness**: judged per kind. A refusal must also make no tool
  calls and cite nothing.
- **Faithfulness**: an LLM judge (`gpt-4.1`, temperature 0, structured output) scores 1–5
  how well the answer's claims are supported by the *full text* of every page the agent's
  tools returned, and lists unsupported claims. The judge also gets human-written expected
  facts, used only to judge behaviour.
- **Pass** requires all criteria for the kind. For answerable questions that means: the
  expected page was retrieved, a source is cited, no false "not found", faithfulness ≥ 4,
  and the judge agrees the question was answered.
